# Secret variable name registry, read by scrub_secrets.py at run time.
# One variable name per line. Matching is case-insensitive. Text after # is a comment.
# Only names whose values are secrets belong here. Settings such as URLs, model names,
# database names or chat IDs do not.
#
# Why it exists: the scrubber already catches common shapes (api_key, password, token).
# A name like EXAMPLE_API_CLIENT_ID or EXAMPLE_STORAGE_ACCESS_KEY_ID slips past those
# shapes, so list it here. For each name the scrubber redacts NAME=value or NAME: value
# (8 or more characters) as CUSTOM_CRED, and the write and command scan blocks it.
#
# Habit: when a service gets its own folder in your secret store, add its variable
# names here in the same change.
#
# Replace the placeholders below with your own names. GAP means no generic shape catches it.

# service: example-storage
EXAMPLE_STORAGE_USERNAME        # GAP: USERNAME is not a keyword
EXAMPLE_STORAGE_ACCESS_KEY_ID   # GAP: the _ID ending breaks the access key match
EXAMPLE_STORAGE_SECRET_ACCESS_KEY  # GAP: _ACCESS_ breaks the secret key match

# service: example-api
EXAMPLE_API_CLIENT_ID           # GAP: CLIENT_ID is not a keyword
EXAMPLE_API_CLAIM               # GAP: no shape covers claim tokens

# service: example-database
EXAMPLE_DB_PASS                 # GAP: PASS is not a keyword (only password)
EXAMPLE_RPC_SECRET              # GAP: a bare SECRET is not a keyword
