## Purpose

This is the catch-all test file for the search scripts. Three classes cover: the fake (hash) embedder, chunking, router helpers, confidence tiers and two small script checks; index maintenance (deleted files, a file edited down to nothing, the embedder marker on source-limited runs, tickets not indexed twice, the health check, the rebuild script); and the folder layout rules of the index (chat threads, meetings, skipped vault folders, and the optional code and standards collections).
