## Purpose

This file holds the regression tests for the search review fixes: how a file's confidence tier is chosen, how scores are combined, which vault folders are left out of the index, how links that point outside a folder are treated, the query-only knowledge collection, collections that are switched off, removal of dead code, and the prompt hook that injects vault context. It has four test classes and 22 test methods, run with the standard `unittest` runner. Nine of the methods need no index and run without `chromadb`; the other thirteen are skipped without it {src:tests/scripts/search/test_review_fixes.py:123} {src:tests/scripts/search/test_review_fixes.py:136} {src:tests/scripts/search/test_review_fixes.py:273}.
