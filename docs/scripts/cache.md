# Cache scripts

The cache scripts keep small JSON files that other scripts fill and the daily brief reads. They know no calendar, tracker or chat tool; a connector plugs in by writing a file {src:scripts/cache/daily_brief.py:4} {src:scripts/cache/daily_brief.py:9}.

Folder: `scripts/cache/`. Tests: `tests/scripts/cache/run.sh`. Files live in the `cache` folder, and the run log in the `logs` folder, both from the path loader {src:scripts/cache/daily_brief.py:202} {src:scripts/cache/run_log.py:61}.

## Seam for a connector

A connector writes `<name>.json` with `atomic_replace`, in this shape {src:scripts/cache/daily_brief.py:15} {src:scripts/cache/daily_brief.py:16} {src:scripts/cache/daily_brief.py:17} {src:scripts/cache/daily_brief.py:18}:

    {"_meta": {"pulled_at": "<ISO time with zone>", "result": "success|degraded|failed",
               "reason": "<one of the run_log reason words>", "reject_count": 0},
     "data": [ ... ]}

Pass records through `phi_guard.scrub` first, then redact secrets, then log the run with `run_log.append`. The shared helper `scripts/connectors/comms/comms_common.py` does the rest for the pull connectors: it wraps data in the envelope, writes the cache file, appends the run log line and always returns 0 {src:scripts/connectors/comms/comms_common.py:44} {src:scripts/connectors/comms/comms_common.py:51} {src:scripts/connectors/comms/comms_common.py:59} {src:scripts/connectors/comms/comms_common.py:114}. It also holds the redaction: `redact_records` replaces each secret in a record's strings with `[REDACTED:LABEL]` {src:scripts/connectors/comms/comms_common.py:79} {src:scripts/connectors/comms/comms_common.py:81}, and the printed run line reports the secret count by label; the run log record keeps its fixed fields and holds no secret count {src:scripts/connectors/comms/comms_common.py:111} {src:scripts/connectors/comms/comms_common.py:59}.

## Pull connectors

Three connectors write cache files: `jira_connector.py` writes `jira.json`, `calendar_connector.py` writes `calendar.json`, and `commits_connector.py` writes `commits.json` {src:scripts/connectors/comms/jira_connector.py:150} {src:scripts/connectors/comms/calendar_connector.py:238} {src:scripts/connectors/comms/commits_connector.py:152}. Each one redacts secrets in the kept records before that write {src:scripts/connectors/comms/jira_connector.py:149} {src:scripts/connectors/comms/calendar_connector.py:229} {src:scripts/connectors/comms/commits_connector.py:143}. They live in `scripts/connectors/comms/` and stay off until first use (see `docs/scripts/connectors-comms.md`).
