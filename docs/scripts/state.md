# Scripts: state

State scripts read and check ticket and vault state. Most only read. The ones that write are the frontmatter backfill (preview by default), the session log retirement tools, the doc drift patrol, and the index backup and restore scripts. Each is listed below with what it writes.

Folders come from the path loader (`scripts/core`). The shell scripts ask `scripts/core/tg_path` {src:scripts/state/backup_index.sh:20} {src:scripts/state/backup_index.sh:21}. The Python scripts import `get_path` from `core.paths` {src:scripts/state/vault_query.py:18}. Tickets live in `02-tickets/PREFIX/KEY/`, so every script that walks tickets goes through `ticket_folder` or `iter_ticket_folders` from the same loader {src:scripts/state/vault_query.py:18}. Python 3.12 is the minimum for the whole scripts tree (`docs/prerequisites.md`).

- once dev has started, `last_block_applied` is `none` or `B-NN` {src:scripts/state/ticket_state_check.py:56} {src:scripts/state/ticket_state_check.py:58} {src:scripts/state/ticket_state_check.py:130};

Example: `ticket_state_check.py T-001 --json`. Exit 0 means no problems, 1 means a problem was found, 2 means not set up, a bad key or a missing folder {src:scripts/state/ticket_state_check.py:17}.
