# Scripts: cron

Cron scripts run on a schedule. They never load a scheduled job by themselves, and the nightly scripts read their folders from the path loader through `scripts/core/tg_path` {src:scripts/cron/nightly_index.sh:23} {src:scripts/cron/nightly_index.sh:35} {src:scripts/cron/nightly_index.sh:36}.

## Setting up a job (safe by default)

`scripts/cron/setup_cron.py` writes one launchd job file from `launchd/job.plist.template` {src:scripts/cron/setup_cron.py:35} {src:scripts/cron/launchd/job.plist.template:3}.

- `--home DIR` is required. The only job file written is `DIR/Library/LaunchAgents/<label>.plist` {src:scripts/cron/setup_cron.py:54} {src:scripts/cron/setup_cron.py:133} {src:scripts/cron/setup_cron.py:134}. The label defaults to `tg-job-<job>` {src:scripts/cron/setup_cron.py:59} {src:scripts/cron/setup_cron.py:81}.
- `--dry-run` prints the file and the place and writes nothing {src:scripts/cron/setup_cron.py:63} {src:scripts/cron/setup_cron.py:158} {src:scripts/cron/setup_cron.py:159}.
- Without `--yes-install-job` the file is written but not loaded {src:scripts/cron/setup_cron.py:170} {src:scripts/cron/setup_cron.py:171}.
- With `--yes-install-job` it loads the job through `--launcher` (default `launchctl`) {src:scripts/cron/setup_cron.py:65} {src:scripts/cron/setup_cron.py:176}. The real launcher is refused when `--home` is not your real home {src:scripts/cron/setup_cron.py:173} {src:scripts/cron/setup_cron.py:174} {src:scripts/cron/setup_cron.py:175}.
- `--remove` deletes the job file, and unloads it only with `--yes-install-job` {src:scripts/cron/setup_cron.py:66} {src:scripts/cron/setup_cron.py:143} {src:scripts/cron/setup_cron.py:146} {src:scripts/cron/setup_cron.py:147}.
- The job copies a fixed list of folder variables (names and paths only, never a secret) into its environment, and writes its output to `<logs>/<label>.log` {src:scripts/cron/setup_cron.py:38} {src:scripts/cron/setup_cron.py:42} {src:scripts/cron/setup_cron.py:151} {src:scripts/cron/setup_cron.py:155}.
- Exit codes: 0 finished, 1 refused, 2 bad arguments or not set up {src:scripts/cron/setup_cron.py:21}.

Example: `setup_cron.py --home "$HOME" --job nightly-index --dry-run`.

Ready made jobs: `nightly-index` (2:00 every day, run with `--notify`) and `weekly-reminder` (Sunday 9:00). Any other script works with `--program` and `--arg` {src:scripts/cron/setup_cron.py:46} {src:scripts/cron/setup_cron.py:47} {src:scripts/cron/setup_cron.py:48} {src:scripts/cron/setup_cron.py:57} {src:scripts/cron/setup_cron.py:58}. `--weekday 0` is Sunday {src:scripts/cron/setup_cron.py:62}.
